# Elena's portfolio

A journalism portfolio site built with [Astro](https://astro.build), plus
(planned) an authenticated Portal for Elena to manage content herself.

This project follows the Spec-Driven Development workflow documented at
`~/.claude/WORKFLOW.md`. Start here:

- `specs/mission.md` — what this is, for whom, and what's in/out of scope
- `specs/tech-stack.md` — pinned dependency versions and why
- `specs/threat-model.md` — data classification and the admin-portal threat model
- `AGENTS.md` — standing rules for anyone (human or agent) working in this repo

## Development

```bash
npm install
npm run dev
```

## Scripts

| Command                           | Does                                                                         |
| --------------------------------- | ---------------------------------------------------------------------------- |
| `npm run dev`                     | local dev server                                                             |
| `npm run build`                   | production build                                                             |
| `npm run preview`                 | preview the production build                                                 |
| `npm run lint`                    | ESLint                                                                       |
| `npm run format` / `format:check` | Prettier                                                                     |
| `npm run typecheck`               | `astro check`                                                                |
| `npm run test:unit`               | Vitest (`tests/unit/`)                                                       |
| `npm run test:e2e`                | Playwright E2E suite                                                         |
| `npm run test:invariants`         | the durable invariant suite (`tests/invariants/`) — runs in full on every PR |
| `npm run check:launch`            | fails while any text is unreviewed or a placeholder; must pass before launch |

The Playwright suites build the site, then serve it on port 4321. Locally,
an already-running `npm run preview` on that port is reused **without
rebuilding**, so run `npm run build` first or the tests check a stale site.

## Content

Elena's Text blocks live in `src/data/text-blocks/*.json` until the Portal
(build step 3) replaces them. French is Elena's own text. English and Italian
values carry `"reviewed": false` until Elena has read them; set it to `true`
once she approves each one. Values we invented, such as the contact email,
carry `"placeholder": true` until she confirms them. The build warns about
both, and `npm run check:launch` lists them.

The link-sharing image `public/og-card.png` is generated by
`node scripts/make-og-card.ts` after a build. Re-run it only if the design
changes.

## Deploying

The site is hosted on **Cloudflare Pages** (free plan, ADR-0002), connected
to this GitHub repository. Setting it up is a one-off, by hand, in the
Cloudflare dashboard:

1. In Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**, and
   pick this repository.
2. Project name: `elena-meyer`, which gives `elena-meyer.pages.dev`. If that
   name is taken, see step 5.
3. Build settings: framework preset **Astro**, build command
   `npm run build`, output directory `dist`, production branch `main`.
   Cloudflare reads the Node version from `.nvmrc`. No environment variables
   or secrets are needed.
4. Save and deploy. From then on:
   - every pull request gets its own **preview URL**, posted on the PR;
   - every merge to `main` deploys to `elena-meyer.pages.dev`.
5. If the address is not `elena-meyer.pages.dev`, update `site` in
   `astro.config.mjs` and `SITE_ORIGIN` in `src/config/site.ts` to match.

**Before launch, nothing is indexed.** While `LAUNCHED` is `false` in
`src/config/site.ts`:

- every page carries `<meta name="robots" content="noindex, nofollow">`;
- the build writes `dist/_headers` so every response carries
  `X-Robots-Tag: noindex, nofollow`.

Check a deployment with `curl -sI https://elena-meyer.pages.dev/fr/`. The
site is unlisted, not locked: anyone with the address can open it.

**Launching** happens through `/sdd-release`, after build step 2b, once
`npm run check:launch` passes. Flip `LAUNCHED` to `true` in its own PR.
